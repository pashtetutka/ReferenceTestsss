# ИТ Справочник

Клиент-серверное Android-приложение для поиска терминов по разработке программного обеспечения. Клиент и сервер написаны на Kotlin. Android-клиент использует Jetpack Compose, MVVM, Ktor Client и DataStore; сервер использует Ktor, JWT и собственную SQLite-базу.

## Возможности

- регистрация и авторизация;
- поиск по названию и определению с фильтром по категории;
- карточка термина с пояснением и примером;
- история последних десяти открытых результатов;
- состояния загрузки, пустого результата и сетевой ошибки с повтором запроса;
- сохранение поискового запроса при пересоздании экрана;
- светлая и тёмная темы.

## Модули

- `shared` — сериализуемые DTO сетевого контракта;
- `server` — Ktor REST API и SQLite;
- `androidApp` — Android-клиент на Jetpack Compose.

## Запуск сервера

Требуются JDK 17 и Gradle 8.11 или новее. Из корня проекта выполните:

```bash
export JWT_SECRET="replace-with-a-long-random-secret"
export DB_PATH="data/reference.db"
gradle :server:run
```

Сервер слушает `http://localhost:8080`. Проверка состояния доступна по `GET /health`.

## Запуск Android-клиента

1. Откройте проект в Android Studio с JDK 17.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `androidApp` на эмуляторе API 26 или новее.

Адрес `http://10.0.2.2:8080` задан в `androidApp/build.gradle.kts` и предназначен для стандартного Android Emulator. Для физического устройства замените `API_BASE_URL` на адрес компьютера в локальной сети. В производственной сборке следует использовать HTTPS и запретить cleartext-трафик.

## Тесты

```bash
gradle :server:test :androidApp:testDebugUnitTest
```

Интеграционный тест поднимает Ktor test host с временной SQLite-базой и проверяет регистрацию, защищённый поиск и получение карточки термина. Ручные сценарии приведены в `docs/test-cases.md`.
