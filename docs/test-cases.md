# Тестовые сценарии

| № | Сценарий | Действия | Ожидаемый результат |
|---:|---|---|---|
| 1 | Регистрация | Ввести корректные имя, адрес и пароль, нажать «Зарегистрироваться» | Создан аккаунт, открыт экран поиска |
| 2 | Повторный адрес | Зарегистрироваться с уже существующим адресом | Показано сообщение о существующем пользователе |
| 3 | Неверный вход | Ввести правильный адрес и неверный пароль | Показано сообщение «Неверный адрес или пароль» |
| 4 | Успешный вход | Ввести действительные данные | Получен токен, открыт экран поиска |
| 5 | Поиск | Ввести «Kotlin» и нажать поиск на клавиатуре | Показан индикатор, затем список результатов |
| 6 | Очистка строки | Ввести текст и нажать значок очистки | Поле пустое, кнопка скрыта, клавиатура закрыта |
| 7 | Пустая выдача | Ввести заведомо отсутствующий термин | Показан плейсхолдер «Ничего не найдено» |
| 8 | Ошибка сети | Остановить сервер и выполнить поиск | Показана ошибка и кнопка «Обновить» |
| 9 | Повтор запроса | Запустить сервер и нажать «Обновить» | Повторён последний запрос, показаны результаты |
| 10 | История | Открыть три результата и активировать пустую строку | Элементы истории показаны от нового к старому |
| 11 | Ограничение истории | Открыть более десяти разных результатов | В истории осталось десять последних элементов |
| 12 | Очистка истории | Нажать «Очистить историю» | Список истории полностью удалён |
| 13 | Поворот экрана | Ввести запрос и изменить ориентацию устройства | Текст поискового запроса сохранён |
| 14 | Тёмная тема | Включить переключатель в настройках | Применена тёмная схема, настройка сохранена |
| 15 | Защищённый API | Запросить `/api/terms` без JWT | Сервер вернул HTTP 401 и объект ошибки |
